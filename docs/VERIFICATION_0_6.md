# 0.6 震源位置、模型预设与接收记录验证

环境：Windows、Release、CUDA 12.8、RTX 4060 Laptop GPU；CPU/OpenMP 与 CUDA 均使用 Float64。生成文件与测试报告位于项目外层 `out`。

## 震源控件

此前震源固定在 X/Y 中心、Z 索引 3。新增独立“震源 / Source”页签，编辑零基 X/Y/Z 索引；X/Y=-1 表示自动居中。中心必须位于 2..N−3，以容纳半径两格的高斯核。显示当前生效物理坐标、当地地表以下深度、主频及空间采样提示，并提供恢复居中和切片定位按钮。

修改位置需应用重建，场和接收记录从零开始。初始化、注入、三维标记、切片标记、VTS 与 CSV 元数据使用同一震源位置。CPU 基础检查验证偏心震源在指定节点注入、导出坐标正确及非法位置不丢弃有效会话；双后端检查使用曲面上的偏心震源比较九场和三分量接收记录。

## 记录模块与预设

参考本机 SeisSim V2 的 ImPlot 绘图、AGC/极值预览和波场色带模块，移植相应纯数据处理及绘图依赖并保留第三方许可。新增道集/单道三分量、六种样式、14 色带、逐道或全局归一化、AGC、道窗口及交互缩放平移；显示缓冲与原始三分量记录分离。CSV 默认兼容原有 Vz 格式，可选原始 Vx/Vy/Vz 全分量。

预设为 X×Y×Z：100×20×100、50×20×50、200×50×100，均保留窄 Y。节点预算扩大至含虚点 1,500,000、单轴最多 256 个物理节点。CPU/GPU 工作内存估算在模型页可见，CUDA 分配前检查可用显存。接收道数为 nx−4；CUDA 接收采样改为多线程块，覆盖大于 32 道的模型。

最大计算步初始值仍为 **1000**，预设不修改该值。预设只暂存几何，应用后重建；自定义震源在缩小模型后超界会被明确拒绝，可恢复居中后重建。

## 验证项目

本次 Release 实测 **5/5 CTest 通过**，总耗时约 307 秒。尺寸/主频矩阵的 32 次运行全部通过有限性、能量和后端对照检查；其中 20 次运行（10 组参数各 CPU/CUDA）波长采样不足，不能据此认定精度合格。三组预设均在真实 CUDA 上完成 40 步，与 CPU 的三分量接收记录最大相对差为 0（本次设备及编译设置下）。

- `ctest --test-dir ../out/build/x64-Release -C Release --output-on-failure`：基础不变量、长时能量与时间收敛、CPU/CUDA 对照、尺寸/主频矩阵、预设及记录处理。
- `--smoke-records`：12 组窗口/字号/中英文/主题组合，覆盖 1024×720 至 1920×1080、18..26 px、六种道集样式、单道三分量、AGC、归一化和道窗口；每张截图前核对三分量原始数据指纹及物理状态不变。截图在 `../out/records-review`，包含中文震源页。
- `--smoke-resize`：增大/缩小模型后的切片、接收选择映射，CPU/CUDA 切换，失败事务保留，以及相机/增益保留。
- `python tools/verify_exports.py`：默认导出含 28×24×28 物理点、13 个点数组和 24 道×552 个样本的原始 Vz，时间轴及数值有效。
- 记录处理检查：20,001 点带正负脉冲数据缩减至最多 2048 点，保持端点和正负极值；AGC 不改变原数据，不向静默段注入振幅，放大不超过设定上限；密度图保持极性与时间位置。
- 三组预设分别推进 CPU/CUDA **40 步**，比较全部接收道 Vx/Vy/Vz、紧凑切片长度和零时刻时间轴；三分量 CSV 检查列数、分量顺序与样本数。明细见 `../out/validation/preset_validation.csv`。

大模型 40 步测试仅验证分配、初期推进、接收覆盖与双后端一致性，不代表百万节点模型已完成整个震源及后期传播的长期稳定性验证。完整尺寸/主频矩阵覆盖小到中型模型；波长采样不足仍须降低主频或细化网格。自由表面反射精度及海绵吸收率仍待标准算例定量对照。
