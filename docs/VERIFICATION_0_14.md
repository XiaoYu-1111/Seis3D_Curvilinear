# 0.14 模型真实尺寸与独立显示参数

日期：2026-10-16。数值传播算子和 CFL 步长公式保持 0.13；本次修改模型信息、显示数据组织、配色、坐标、参数限值的一致性和说明文档。

## 尺寸

建模页与诊断页显示当前模型真实 X/Y/Z 包围盒尺寸、Z 范围和地表 Z 范围；三维视口显示真实尺寸。它们取自当前已成功重建的物理节点坐标，包含海绵物理节点，排除每面三层虚点。失败重建保留原尺寸。

网格编辑区另显示待应用跨度 `(N−1)*h`。例如 200×20×200、h=10 m 的网格跨度是 1990×190×1990 m，并不是 2000×200×2000 m。地形 A=20 m/L=300 m 时，真实 Z 范围为 −20..1990 m，包围盒高度为 2010 m。

二维切片标题区域显示当前切片自身的真实跨度；足够大的绘图区显示米制坐标刻度，并保持物理比例、缩放、平移与切片联动。Z 正向向下；X-Y 曲面切片仍绘制水平 X/Y 坐标。显示页可分别关闭尺寸或坐标。

## 显示参数真正分开

| 项目 | 波场 | 模型物性 |
|---|---|---|
| 分量 | Vz/Vx/Vy/速度模/压力（负平均应力） | Vp/Vs/密度 |
| 色带 | 独立 W 切换 | 独立 E 切换 |
| 范围 | 固定速度/应力参考或物理峰值 | 三种物性各自的手动范围或材料最小/最大值 |
| 增益 | 可调 | 不使用波场增益 |
| 归一化 | 默认勾选，刻度 −1..1 或 0..1 | 始终保留物理单位 |
| 色标开关 | 独立 | 独立 |

显示页有“仅波场 / 仅模型 / 模型与波场叠加”。默认仅波场，保留原启动显示方式。叠加时零波场透出模型，透明度和弱波阈值可调；两条色标分别表示两套映射。原始场、材料系数、能量和接收记录保持 SI，不经过显示增益或颜色归一化。

Q 现在仅循环五种波场分量，模型物性在独立组中选择，避免跨越速度/介质时使增益和色标含义混淆。Shift 反向和输入焦点保护保留。显示模式、两类分量/色带/色标开关、模型自动/手动范围及尺寸/坐标开关随界面偏好保存；老偏好文件缺少新键时采用新功能默认值。

模型自动范围由配置材料表决定，尚未覆盖物理节点的地层也可能参与范围；数值诊断会单独提示未解析/未覆盖地层。这种全配置范围保证各切片颜色可比较，未把当前切片的局部极值冒充全模型范围。

## 代码优化

- 公共几何信息函数区分名义网格跨度与真实物理包围盒，真实范围仅在成功重建时扫描。
- 波场/模型切片各自缓存。模型只在重建、切片位置或物性分量改变时读取，推进时间步不重复读取；不下载全体积。
- 两种视图共用颜色映射、叠加和色标范围，减少单位或颜色不一致。
- 二维、三维切片预先计算每个节点的坐标/颜色，相邻单元复用，避免对同一角点重复着色。
- 最大 CPU 线程数与总步数使用公共常量，减少界面/求解器参数上限漂移。

## 参数审查

| 参数或说明 | 审查后的当前值/行为 |
|---|---|
| 默认应用核心 | 可用 CUDA 优先；仍可选择 CPU |
| 初始停止条件 | 1 s 或最多 5000 步，先到者停止 |
| CFL | 默认/最大 0.8，最小 0.02；几何/阻尼/源采样共同限制 |
| 首个完整模型预设 | 200×20×200，12 Hz，源 100/10/50，0.5 s，CFL=0.8 |
| 其他模型预设 | 100×20×100、50×20×50、200×50×100；保留有效源和停止设置，越界源按相对位置适配 |
| 物理节点限制 | 各轴 8..256，含三层虚点总数最多 1,500,000 |
| 总步数上限 | 两种核心均为 20,000，错误信息不再误写为 CPU 专用 |
| CPU 手动线程数 | 核心原支持 0..64，旧 UI/偏好仍截到 32；本次统一到 64。0 自动、自动最多 8 |
| 波场分量 4 的名称 | 修正为压力 `−trace(sigma)/3`（Pa）；数值不变，VTS 历史字段名 `MeanNormalStress` 保留兼容 |
| 黄土文档 | 旧默认 1000 步和固定约万步说明已按当前停止/CFL 设置修订 |
| 旧用户指南 | 原小预设、预设保留规则、计算核心入口及 Q 八分量描述已修订 |
| 历史翻译 | 删除旧 350,000 节点、双层虚点、8..128、旧 Q/W 映射等失效条目 |

启动的自定义小模型与完整验证预设是不同工况：前者保持结构体默认的 28×24×28、1 s、5000 步；只有选择完整验证预设才暂存 200×20×200 和 0.5 s。界面明确显示当前尺寸、预设匹配状态及待应用参数，避免把预设参数误认为全部启动默认。

## 验证方式

新增 `curvilinear_model_display`：检查节点跨度、虚点排除、真实地形 Z 范围、模型与波场 RGB/色标相互独立、单独图层不会读取缺失的另一图层数据、零波场叠加、独立色标开关和 Q 五分量循环。

Release 编译通过；六项针对性 CTest **6/6 通过**。独立显示、导航快捷键及色标 GUI 检查各十二组图像通过；缩放/尺寸重建、CPU/CUDA 切换和失败事务检查通过，原始接收记录指纹保持不变。

`--smoke-model-display` 使用真实 CUDA 生成黄土分层波场，检查材质缓存不会随时间步重复下载；十二组实际 OpenGL 图像覆盖 1024×720..1920×1080、18..26 px、中英文和十种主题，轮换三种模式、Vp/Vs/密度、速度/应力、归一化/SI 及独立色标开关。截图位于 `../out/model-display-review`，各切换后检查原始记录、物理修订号、相机和波场增益不变。
