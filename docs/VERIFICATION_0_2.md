# 0.2.0 验证记录

日期：2026-10-15。环境：Windows，Visual Studio 2022 / MSVC 19.44，Release 配置；图形工作台成功创建 OpenGL 4.3 核心上下文。

## 构建

CPU 静态核心、CLI、数值验证程序和独立 ImGui/OpenGL 工作台均成功构建。最终构建输出无编译或链接警告。GLFW/GLEW 使用 DLL 导入库，运行 DLL、着色器及许可证自动部署到 EXE 同级目录，避免原静态库运行库配置冲突。

所有生成文件位于本项目外层 `out`，没有复用 SeisWave Lab V2 的 CMake 缓存。

## 数值检查

CTest 的 `curvilinear_cpu_invariants` 通过，覆盖平面度量、曲率相关 CFL、解析场梯度加密、推进批次一致性、表面牵引变化率、接收时间轴和非法参数防御。

| 检查 | 结果 |
|---|---|
| 平面 Jacobian/逆度量最大误差 | 当前双精度测试输出为 0 |
| 解析场物理梯度粗网格误差 | 0.00152112（按波数归一化） |
| 加密一倍后的误差 | 0.000100132 |
| 误差下降倍数 | 15.1912，接近空间四阶的 16 倍 |
| 整批与每批七步的 Vz | 逐值相同 |
| 测试算例未投影牵引变化率相对残差 | 5.56513e-16 |
| 非法参数及超预算网格 | 拒绝，原可用会话保留 |

默认模型 28 × 24 × 28、间距 10 m、主频 12 Hz、时长 0.22 s，完成 535 步。实际 dt 约 0.411215 ms；最小 Jacobian 为 1，CFL 使用的最大逆度量范数为 1.781438。最终物理区域峰值 |Vz| 约 0.001944 m/s，全部九个场分量有限，未投影的相对牵引变化率残差约 7.25e-16。

## 图形与文件

隐藏窗口实测推进至第 401 步，即约 0.164897196 s，并用实际 OpenGL 帧缓冲生成 1600 × 1000 原始截图。画面显示三维曲面网格、三张物理切片、波场色带、单道及 24 道接收记录；运行结束未报告 OpenGL 错误。

- 13 个点数据数组及显式坐标的 tuple 数正确，所有数值有限。
- 快照时间、dt、步号元数据一致。
- CSV 包含 24 道、402 个样本，首样本时间为 0，间隔均匀。
- CSV 最后时间与 VTS 快照时间一致。

## 解释范围

这些检查验证工程可运行、空间导数变换、局部边界代数条件和数据完整性。空间梯度加密并非完整弹性波自由表面解的收敛证明，牵引变化率小也不证明能量与反射振幅正确。与 CGFD3D 标准算例的定量对照、完整波动解的收敛和边界反射率仍待完成；当前吸收层是海绵层，CUDA 后端尚未实现。
