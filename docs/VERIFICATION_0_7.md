# 0.7 网格、色标与工作区验证

2026-10-16，Windows Release、CUDA 12.8、RTX 4060 Laptop GPU。此版本修改显示、窗口管理和说明文档，未修改数值点算子、源和边界算法。

## 改动

- 二维及三维切片逐个连接实际物理节点，不再按固定约 12 条线抽样。显示 Nx×Nz、Ny×Nz 或 Nx×Ny 节点数；网格、十字线、地表线框独立开关，网格透明度可调。三维叠线采用深度偏移避免与切片面闪烁。
- 二维/三维波场和色标共用参考项目的 14 组五节点色带。带物理量名称、单位和真实饱和值刻度；速度模从零开始，其他量正负对称。主题不再改变波场色带的零值颜色。自动速度参考共用最大速度模，应力参考独立。
- 七个面板接入关闭状态，页签/标题栏提供 ×，工作区菜单重新打开，F 恢复全部面板和默认布局。可见状态保存至 `../out/ui/preferences.cfg`。关闭显示不改变求解器状态。
- 运行绿色、模型蓝色、显示青色、导出紫色、网格/警告琥珀色、重置红色；分别调整深浅主题明度。小于 1500 px 时合并中心页签，切片控制压缩至一行以保留绘图和色标空间。
