# 0.15 网格、快捷键及参数重建检查

验证日期：2026-10-16。构建为 Windows Release、CPU/OpenMP + CUDA Float64；可执行文件位于 `../out/bin/Release`，生成图像和测试结果均位于外层 `out`。

## 操作与显示

以本地规则网格项目 `CMakePro_CUDA_SeisSim_V2/src/Seis3D/Workspace3D.cpp` 的三维快捷键为参考：Space 运行/暂停、N 单步、C 清空、R 适配视图、Q 波场色带、W 波场分量、E 模型色带、Shift 反向、G 网格、B 吸收区域、V 三维切片、F1 说明。当前工作台没有规则网格程序的首页，Tab 保留控件导航；V 对应当前可用的三维切片显示。另保留 F 恢复布局、Ctrl+S 导出 VTS。

顶部命令栏常驻清空和帮助按钮；有暂存参数时出现应用按钮，窄窗口自动换行。编辑控件、打开菜单时暂停工作区快捷键。F1 说明窗可用 F1、Esc 或关闭按钮关闭。

尺寸和坐标使用普通十进制，去除多余末尾零：1990、2000、1990.125、−20、0.25；场振幅仍可使用科学计数法。修改参数后，生效网格/dt 与待应用配置分开显示。

## 网格与容量

新增 100³、200³、300³ 三项预设及快捷按钮，保留原四项。各轴上限 300，存储点数上限 `(300+6)³=28,652,616`。缩小预设时适配越界源和自定义接收排列，有效源索引保留。

分配前检查当前可用 RAM/VRAM，保留主机 20%、设备 10% 余量；失败保留旧会话。用户点击“按可用内存适配网格”才缩小节点数，保留间距，所以物理尺寸随之改变。

修正诊断工作集沿用 CPU 数组估算的问题：CUDA 诊断现在合计实际核心的 RAM/VRAM，接收工作区按生效步数上限估算；模型页仍分别列出待应用模型的 RAM/VRAM。

均匀 300³ 的 CUDA 估算为 16.6663 GiB；本机 8 GiB GPU 无法运行，已验证其预检拒绝且原会话保留。对假设 64 GiB 可用主机内存、8 GiB 可用显存，适配结果为 225³；实际数值依当时可用容量确定。未执行 300³ 全尺寸计算。

另执行 `seis3d_configuration_validation.exe --capacity200`：实际 CUDA 200×200×200 初始化、推进两步、有限紧凑切片读取和原位清空通过，dt=1.31579 ms。该工况使用 10 m 间距、20 m/300 m 地形、0.1 s 计划时长和两步上限；不把短测称为长时波形精度验证。

## 时间步与清空

初始化和预览共用 `timeStepPlan3D`：仍取波传播/几何、阻尼、源采样三项最小值，再以 `T/ceil(T/dt_safe)` 覆盖完整时长；步数上限只截断。平地直接构造精确 Cartesian 坐标和单位度量，消除已知线性网格上不必要的数值微分及舍入。曲面继续重新计算四阶度量和相邻平面距离。

新增配置回归连续修改间距、Vp、主频、分层最大 Vp、吸收、Ny、时长/最大步数共八组配置，以独立平地公式核对每次 dt；曲面不同 Nz 的重建与全新会话比较 dt 和展平深度。曲面几何未应用时，不用旧几何显示新 dt。

C 在 CPU/CUDA 上原位清空场和 RK 缓冲、步号、源峰值、故障、记录及推进计时；坐标地址和 dt 保持，显示修订号变化，记录恢复 t=0 单样本。清空后重新推进与全新同参数会话的切片精确一致。界面验证清空不应用待修改 Vp，也不重分配几何。
