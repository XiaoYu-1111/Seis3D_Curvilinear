# 0.4 稳定性与 CPU/CUDA 验证

环境：Windows x64、VS2022/MSVC 14.44、CUDA 12.8、RTX 4060 Laptop GPU、Release Float64。CUDA 编译关闭 FMA 收缩以便 CPU 对照；未启用 fast-math。

## 参考代码与本次落实范围

参考目录为 `Git_张伟曲网格三维有限差分算法/CGFD3D-master/CGFD3D-master/forward`：

- `blk_t.c::blk_dt_esti_curv`：逐点计算到八个相邻平面的距离，取全局最小值。本项目增加同一几何距离构造，再与已有逆度量 CFL 取更小上限；没有沿用原 DRP 格式的 CFL=1.3。
- `fd_t.c::fd_set_macdrp`：核对经典 RK4 的 1/2、1/2、1 阶段和 1/6、1/3、1/3、1/6 权重。
- `sv_curv_col_el_iso.c`：核对局部速度导数零牵引条件。当前 CPU/CUDA 共用局部表面闭合；没有宣称已移植其全部保守 Traction Image 与分层偏置格式。

本次没有复现旧基线默认模型的发散，因此没有用额外人工衰减掩盖波形。新增几何/阻尼约束、逐步能量诊断与失败回退，并扩大验证工况。

## 自动验证

执行 `ctest --test-dir ../out/build/x64-Release -C Release --output-on-failure`。

1. `curvilinear_cpu_invariants`：平面度量、曲面梯度加密、OpenMP/串行一致性、步数上限、CFL 输入与时间步上下限、自由表面变化率残差、接收时间线、视图映射。
2. `curvilinear_long_time`：20×18×24 节点、dt 自动选择，模拟 1 秒。地表振幅/波长/Vs 分别为 (0,240,1700)、(20,240,1700)、(35,240,1700)、(35,80,1700)、(20,120,150)、(20,120,2550)，单位为米和米/秒。检查有限性、独立应力柔度能量公式与内置能量一致，以及 t>0.6 s 的最大能量小于全程峰值的 20%。低 Vs 工况用于稳定性压力测试，其波长分辨率不足以用于精度结论。
3. 同一长时测试还将 CFL 取 0.22、0.11、0.055，比较最终 Vz；本机最大范数差值之比约 16.7，超过要求的 4。
4. `curvilinear_cpu_cuda`：平地与振幅 30 m 曲面，18×16×24 节点、0.25 秒，比较九场、全部接收波形、五种分量三切片、能量、表面变化率、重建事务和最大步数。场和接收的相对误差要求 <1e-9，本机实测逐值一致。构建未启用 CUDA 或无设备时，此项明确显示 skipped。
5. 对两核心构造极低密度的溢出压力用例，拒绝首个非有限步，核对步数/版本/接收样本保持原状态、锁定故障并可经正常参数重建恢复。

首轮计时（包含逐步诊断，不含初始化与导出）：两个小模型的 CUDA 约 0.37/0.56 秒，CPU 串行约 1.09/1.65 秒。此处比较的是单线程基准，不能据此推断相对 OpenMP 的加速比或大模型表现。

## 图形与数据检查

`SeisWaveLab_Curvilinear.exe --smoke-cuda` 实际选择 CUDA 运行到约 3/4 时刻，导出 VTS/CSV、渲染三维与三切片，保存 `../out/gui_smoke.ppm` 后退出。`--smoke-resize` 另检查模型大小改变。两种模式均验证 CPU/CUDA 双向切换、初始化失败保留原会话、切换后场与记录清零，以及相机和增益保留。

## 科学适用范围

机械能采用物理 Jacobian 体积加权的动能与各向同性应力柔度能之和，是诊断积分；当前自由表面离散未建立严格离散能量估计。`10,000×` 后期增长阈值是故障保护，不能代表稳定性定理。仍需完成与 CGFD3D 匹配源函数/边界的波形与反射定量对照、空间波场收敛及吸收反射率验证。
