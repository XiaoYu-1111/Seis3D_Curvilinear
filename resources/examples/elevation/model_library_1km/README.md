# 1 km 地表高程模型库

这些文件是人工构造的二维地表输入，用于比较地形形态对波场的影响，不代表实测地形。各模型独立存为 CSV，**无需修改或重新编译程序，也没有加入内置示例菜单**；在高程编辑器中选择文件即可导入。

## 统一格式

- 水平范围：X=0–1000 m，采样间距 1 m，每个文件 1001 个样点。
- 两列：`x_m,elevation_m`，单位均为米，高程向上为正。
- 零高程为平地基准；山丘最高 +100 m，沟谷最低 −100 m，具体以各模型为准。
- 下面的宽度均指两端回到零高程的水平跨度，**不是半高宽**。
- 文件的 1 m 采样间距不等于模拟网格间距，导入后由程序插值。

## 形状构造

常规山丘、沟谷采用紧支撑余弦钟形：

$$
B(x;a,w,A)=\frac A2\left[1-\cos\left(2\pi\frac{x-a}{w}\right)\right],
\qquad a\le x\le a+w,
$$

区间外为零。正 A 为山丘、负 A 为沟谷。模型 01、02、03、04、07 由不重叠的钟形组合，连接点的构造高程与一阶导数连续。

模型 05 对峰顶或谷底的两侧分别采用半余弦过渡，保持端点及极值处斜率为零，同时改变两侧坡长。模型 06 的平台和零高程之间使用五次平滑函数

$$
S(t)=6t^5-15t^4+10t^3,\qquad 0\le t\le1,
$$

使构造高程在连接处具有连续的一、二阶导数。模型 08 在 100–900 m 内采用 `100 sin(2π(X−100)/200)`，乘以由同一五次函数构造的首尾窗：100–200 m 从 0 增至 1，200–800 m 为 1，800–900 m 从 1 降至 0。它们均是样点数据，实际导入后的曲线由程序的 PCHIP 插值确定。

## 手动导入

1. 进入“二维 → 建模 → 外部地表高程”。
2. 点击“选择高程文件”，从本文件夹选取所需 CSV，再点击“载入高程”。
3. 为方便统一比较，将**高程基准设为 0 m**。程序默认用样点平均高程初始化基准，双山丘等模型的默认基准会不同。
4. 要显示完整 1000 m，建议先设 **Nx=401、Nz=401、网格间距=2.5 m、展平深度=0（自动）**。这是几何起始配置，不是对任意材料和主频的精度保证。
5. 按“完成”，再“重置并应用参数”，确认生效网格、几何质量、dt 和目标频带的分辨率。

这些文件只描述地表，不设置地下层状介质、震源、接收排列、主频或计算后端。对比不同地形时，应保持物性、源的物理定义、接收几何和模拟时长等条件一致，并明确接收点是按埋深还是绝对坐标布置。

模型 04 的窄山及模型 05 的短坡更陡，可能增加局部网格剪切、缩短自动时间步；比较时不要把“运行完成”单独当作空间精度证据。高程格式和一般操作另见[上一级示例说明](../README.md)。
